# run-store

Append-only store of the analyses run from GitHub (written by the `Assessor bot` and `CI` workflows; do not edit by hand).

- `runs/` – one directory per run (spec, script, prepared data, manifest, report…), plus `runs/audit/` (append-only audit and pseudonymised LLM logs)
- `requests/` – state of each analysis request (one JSON per issue)
- `demo/` – reference demo regenerated by CI on every push to `main`

The git history of this branch is the full trace: nothing is ever deleted.
The pseudonym map (token → identifier) is never committed (see `.gitignore`).
